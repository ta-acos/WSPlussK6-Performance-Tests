6. Usage Notes

  • HTML report files saved under src/reports/ follow pattern: {test}-{scenario}-report.html.
  • Set CONFIG_ENV to target environment (e.g. --env CONFIG_ENV=autotest).
  • No‑pacing variants disable user think time via PACING_MODE='none'.
  • Verbose report variants embed collapsible debug logs inside the HTML.
  • Always clean old reports before long suites: npm run reports:clean.
